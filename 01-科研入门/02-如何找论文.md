# 02 · 如何找论文

## 方法一：从重要会议和期刊中寻找

AI 方向**以会议论文为主**。每次会议放榜后可以看到所有文章列表；如果是 OpenReview 的会议，还能看到所有投稿文章。可基于关键词、论文题目找到与自己方向相关的文章。

**因此：每次会议投稿截止和放榜之后，都应对相关文章做一次筛选和阅读。**

### 常见方向的重点 venue

| 方向 | 会议 / 期刊 |
|---|---|
| 机器学习 | ICML、NeurIPS、ICLR |
| 自然语言处理 | ACL、EMNLP、COLM |
| 计算机视觉 | CVPR、ICCV、ECCV |
| 人工智能 | AAAI、IJCAI |
| 数据挖掘与信息检索 | KDD |
| 综合性高影响力期刊 | TPAMI、JMLR、TMLR、TKDE、Nature Machine Intelligence 等 |

> **这份名单不是固定的，也不是评价论文价值的唯一标准。** 进入具体方向后，应根据导师建议和该领域的引用习惯，建立自己的重点 venue 列表。

## 方法二：从"种子论文"开始扩展

刚进入一个方向时，有效的方法是先找到几篇**种子论文**，再以它们为中心扩展。

适合作为种子论文的：

- 近几年发表的**高质量 Survey**
- 该方向**公认的代表性工作**
- 与自己的研究问题**最接近的论文**
- 被广泛使用的 **Benchmark 论文**
- 最近两年顶会中的代表性论文
- 导师或同学推荐的论文

> 新手最常犯的错：直接搜关键词，然后随机读。先 establish 种子论文，再扩展，效率差一个量级。

## 方法三：沿着引文网络"顺藤摸瓜"

读一篇文章不仅仅是读这一篇，而是**以一篇文章为引子**，通过 Introduction、Related Works、Compared Methods、References 去找更多相关文章。

- **向后追踪**：查看论文引用了哪些早期工作 → 找到该问题的源头与经典方法
- **向前追踪**：查看谁引用了这篇论文 → 找到最新进展与后续改进

> 实操建议：找一篇种子论文后，把它引用的、和引用它的，各挑 5 篇高质量的先读。通常一个方向的骨架就出来了。

## 配套工具

- **Google Scholar** —— 查引用关系（被引次数是关键信号）
- **OpenReview** —— 看会议投稿与评审意见（能学到审稿人怎么想）
- **arXiv** —— 每日新论文
- **Hugging Face Daily Papers** —— 社区筛选过的热点
- **Connected Papers / Semantic Scholar** —— 可视化引文网络

## 配套动作（配合 `17-好的科研习惯.md`）

1. 每天 10–20 分钟浏览 arXiv 分类 / HF Daily Papers / 会议列表
2. 读过的有价值文章存进 Zotero 或飞书，标注**为什么值得存**（idea 有启发 / 实验好 / 写作好）
3. 用引文网络做**主动扩展**，而不是被动等推荐
