# 10 · 如何写论文 · Experiments

## Experiments 的大致结构

```
1. Experimental Setup
2. Main Results
3. Ablation Study
4. Analysis / Further Study
5. Case Study / Visualization
6. Robustness / Generalization
7. Efficiency / Cost Analysis
```

> ⚠️ **并不是每篇论文都需要全部包含。**
> **实验结构应服务于本文贡献，而不是为了显得实验很多。**

这句话很重要。堆实验 ≠ 好论文。每个实验都应该回答一个具体问题。

## 先写 Experimental Setup

Experimental Setup 是 Experiments 的基础，作用是**让读者理解实验是在什么条件下完成的**。

通常需要交代：

- 使用哪些 **datasets / benchmarks**
- 比较哪些 **baselines**
- 使用哪些 **evaluation metrics**
- 模型**实现细节**是什么
- **训练和推理参数**是什么
- 实验**重复次数、随机种子和统计方式**是什么
- 所有方法是否在**公平条件**下比较

> 这一部分要清楚、具体，**避免模糊表达**。如果细节过多可以在附录中进一步补充。

### 公平比较是底线

- 所有方法用**相同的**数据划分、评测协议、算力预算
- 如果 baseline 是你自己复现的，要说明复现方式和是否引用原作者报告的数字
- 不要用"更好的超参"给自己刷分

> 审稿人一旦发现比较不公平，基本直接拒。

## Main Results 要服务于核心结论

Main Results 通常是 Experiments 中最重要的部分，往往对应论文的**主表和主图**。

这一节要回答：

- 本文方法是否**优于**已有方法？
- 在**哪些**设置下优？优势有多大？
- 有没有**不符合预期**的结果？（有的话要诚实说明）

## Ablation Study

消融是回答"**方法里每个部分都有用吗**"的唯一手段。

- 每去掉一个模块，性能掉多少？
- 如果去掉某模块性能不掉，那这个模块就是多余的——要么删除，要么想清楚它真正的价值

> 审稿人非常喜欢看消融。缺消融是常见的拒稿理由。

## Analysis / Further Study

超过"我们更好"的深度分析。比如：

- **为什么**方法有效？（机制分析）
- 在什么条件下**失效**？
- 超参数敏感性如何？

→ 这类分析往往能发展成 `04-如何想Idea.md` 里的"切入 3：从是否有效反推机制"

## 常见错误

| 错误 | 后果 |
|---|---|
| Setup 写得太模糊 | 无法复现，被质疑 |
| 只报 accuracy，不报标准差 / 多种子 | 结果不可信 |
| 没有消融 | 审稿人认为无法验证贡献 |
| 只报成功的实验 | 被认为挑选结果 |
| 实验结论与提出的问题不对应 | 逻辑不闭环（见 `06-摘要Abstract.md`） |

## 自检

- [ ] Setup 是否具体到能复现？
- [ ] 比较是否公平（同数据/同协议/同算力）？
- [ ] 有消融吗？每个模块都有对应的消融项吗？
- [ ] 结论是否**呼应**了摘要里提出的问题？
- [ ] 有没有诚实报告失败案例或限制？
