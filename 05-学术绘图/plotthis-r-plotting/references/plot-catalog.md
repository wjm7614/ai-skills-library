# Plotthis 图型索引

参考版本： 0.14.0 。由 NAMESPACE 与 Rd alias 自动生成。

先按下面的意图映射选择候选，再打开该函数的 API；Rd 中 usage 是签名、arguments 是参数契约、value 是返回值、examples 是上游示例。只读相关文件，不批量加载。

| 用户意图 | 候选函数 |
|---|---|
| 柱状、分组柱状、拆分柱状、瀑布 | BarPlot / SplitBarPlot / WaterfallPlot |
| 散点、折线、趋势、面积、棒棒糖 | ScatterPlot / LinePlot / TrendPlot / AreaPlot / LollipopPlot |
| 箱线、小提琴、蜂群、抖动 | BoxPlot / ViolinPlot / BeeswarmPlot / JitterPlot |
| 分布、直方、山脊 | DensityPlot / Histogram / RidgePlot |
| 热图、联合热图、相关矩阵、成对相关 | Heatmap / LinkedHeatmap / CorPlot / CorPairsPlot |
| 火山、曼哈顿、富集 | VolcanoPlot / ManhattanPlot / GSEAPlot / GSEASummaryPlot / EnrichMap / EnrichNetwork |
| 降维坐标、特征、速度、聚类树、点阵 | DimPlot / FeatureDimPlot / VelocityPlot / ClustreePlot / DotPlot |
| 流向、桑基、弦图、环形关系、网络 | AlluvialPlot / SankeyPlot / ChordPlot / CircosPlot / Network |
| 集合与交集 | VennDiagram / UpsetPlot |
| 雷达、ROC、QQ、稀释曲线 | RadarPlot / SpiderPlot / ROCCurve / QQPlot / RarefactionPlot |
| 饼、环、词云 | PieChart / RingPlot / WordCloudPlot |
| 空间点、形状、掩膜、底图 | SpatPointsPlot / SpatShapesPlot / SpatMasksPlot / SpatImagePlot |
| 主题、四边框、调色板 | theme_this / theme_blank / theme_box / palette_this / show_palettes |
