# 07 · 如何写论文 · Introduction

> Introduction 基本上是 **Abstract 的扩写版本**，依然遵循同一逻辑：
> **研究领域 → 已有工作 → 未解决问题 → 本文工作**

## 好 Introduction 要完成的四件事

1. 说明**研究领域为什么重要**
2. 总结**已有研究已经做了什么**
3. 指出**仍然存在的问题、空缺或不足**
4. 说明**本文要做什么、怎么做的、取得了什么结果**

## 四段式结构

### 第一段 · 建立研究领域

要回答：**这个领域为什么值得关注？**

可以写：

- 该问题在科学、工程、医学、社会或产业中的重要性
- 该方向近年来受到关注的原因
- 该任务的应用场景或理论意义
- 基本概念、对象或现象的简要定义

> ⚠️ **注意：不要一上来就写自己的方法。先让读者理解这个问题为什么重要。**

**常用句式功能**：

| 功能 | 句式 |
|---|---|
| 重要性 | `X is important because ...` |
| 趋势 | `X has received increasing attention due to ...` |
| 核心地位 | `X plays a central role in ...` |
| 技术推动 | `Recent advances in Y have made it possible to ...` |

### 第二段 · 回顾已有研究

要回答：**别人已经做了什么？**

- **这里不是写完整文献综述**，而是选择与本文最相关的工作，为后面的 gap 做铺垫
- 可以写：已有方法的主要类别；代表性工作解决了哪些问题；这些工作带来了什么进展

### 第三段 · 指出未解决的问题（Gap）

这是全文的**转折点**，也是审稿人最关注的地方。

要从第二段的"进展"自然过渡到"但是还不够"：

- 已有方法在什么条件下失效？
- 缺的是能力、效率、泛化性，还是可解释性？
- 这个缺口是不是**重要**的？（不重要的 gap 撑不起一篇论文）

### 第四段 · 本文工作

说明本文做什么、怎么做、结果如何。通常包括：

- 提出了什么方法 / 观察 / benchmark
- 核心 insight 是一句话能说清的
- 在什么任务上取得了什么具体结果
- （可选）贡献列表 Contributions，2–4 条

## 常见错误

| 错误 | 后果 |
|---|---|
| 第一段就开始讲自己的方法 | 读者不知道问题为什么重要，无法建立动机 |
| 第二段堆成长篇综述 | 冲淡主线，gap 说不清 |
| gap 写得太弱 | 审稿人判定"问题不重要 / 已被解决" |
| 第四段列一堆贡献但没有主线 | 读者记不住你到底做了什么 |

## 自检

- [ ] 四段是否都在？顺序对不对？
- [ ] 每段第一句话是不是该段的主旨句？
- [ ] 从第三段到第四段的转折是否自然？
- [ ] 全文读下来，动机→方法→结果的链条有无断裂？
