# 17 · 一些好的习惯

## 1. 保持稳定的学术输入

每天工作前抽出 **10–20 分钟**，浏览与研究方向相关的内容：

- **arXiv** 分类
- **Hugging Face Daily Papers**
- **会议论文列表**
- 学术平台推荐

目的：了解近期出现的**新论文、新问题和新方法**。

> 关键是"稳定"。每天 15 分钟，一年是 90 小时，比偶尔突击一天读 20 篇有效得多。

## 2. 建立自己的知识积累系统

阅读过的**有价值的文章**（包括但不限于：idea 很有启发性、实验效果很好、文章写作很好等）要存储管理起来，后续有需要方便翻阅。

**可用工具**：Zotero、飞书、多维表格，或其他工具。

> 建议：存的时候顺手标一句"**为什么值得存**"。半年后你完全想不起当时为什么存它。

## 3. 记录实验日志

每次重要实验都建议记录以下内容：

- 实验**目的**或待验证**假设**
- 与上一组实验相比**修改了什么**
- **数据、模型和参数配置**
- **随机种子**及运行环境
- **核心实验结果**
- 结果**是否符合预期**
- 当前**结论**
- **下一步准备做什么**

> ⚠️ **失败实验和负面结果同样需要记录。**
> 它们能够帮助我们**排除错误方向**，也可以防止**几周后再次重复相同的尝试**。

### 一个最小实验日志模板

```markdown
## [日期] 实验名：____________

**目的 / 假设**：
**对比上次的改动**：
**关键配置**：数据=___ 模型=___ 参数=___ seed=___
**结果**：
**是否符合预期**：是 / 否 → 原因推测
**结论**：
**下一步**：
```

## 4. 问题与解决方案记录

实验过程中遇到的**问题及其解决方法应及时记录**。

好处：

- 避免以后重复排查
- 方便帮助团队中的其他同学
- **即使问题暂时没有解决，也应记录已经尝试过的方法**

> 这一条在带新人/被带的时候价值翻倍。你踩过的坑，别人也一定会踩。

## 5. 及时记录和整理想法

有 idea 及时记录，**好记性不如烂笔头**。

科研想法往往是在**读论文、做实验、参加组会或与人交流**时突然产生的。如果不及时记录，很容易在之后遗忘。

> 建议：手机备忘录 / 飞书 / 一个纯文本文件都行，重点是**零摩擦**。记录成本越高，你越不会记。

## 这套习惯的价值

| 习惯 | 解决的问题 |
|---|---|
| 稳定输入 | 不知道领域在发生什么 |
| 知识管理 | 读过就忘，重复读同一篇 |
| 实验日志 | 重复踩坑，无法追溯为什么当初放弃某方向 |
| 问题记录 | 同一个人重复问同一个问题 |
| 想法记录 | 灵感来了又走了 |

> 这五条都**不需要天赋**，只需要坚持。这也是为什么它们是"好的习惯"而不是"好的技巧"。
