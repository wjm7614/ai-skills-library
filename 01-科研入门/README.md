# 01 · 科研入门

从「不知道科研是什么」到「投出一篇论文」的完整流程。

**每篇都可独立加载**，也可从 `SKILL.md` 总入口按阶段路由。

## 阶段地图

```
准备期 ──► 选题期 ──► 执行期 ──► 写作期 ──► 投稿期 ──► 长期习惯
  │          │          │          │          │          │
  01         02 03 04   03 04      05~11      12 13      17 18
            找/读/想               写作八章    图/Rebuttal
                                    
交流线（全程）：14 汇报 · 15 组会 · 16 参会
```
