# dsh-skills 技能索引

本目录是**给 DeepSeek Harness 用的扁平技能层**。共 **257** 个技能。

## 用法

把本目录配成 DSH 的 skill 根目录即可（三选一）：

```bash
# 方式 1：软链接到用户级目录（全机可用）
ln -s <本目录绝对路径>/* $DSH_HOME/skills/      # macOS/Linux
New-Item -ItemType Junction -Path "$env:DSH_HOME\skills\ai-skills" -Target "<本目录>"   # Windows

# 方式 2：写进 DSH 配置
# { "customSkillDirs": ["<本目录绝对路径>"] }
```
